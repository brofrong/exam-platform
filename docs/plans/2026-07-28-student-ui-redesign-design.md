# Student UI Redesign

Дата: 2026-07-28  
Статус: согласован (brainstorming)

## Цель

Переделать интерфейс ученика: боковая навигация на десктопе, нижнее меню на мобилке, убрать верхнюю шапку на `/app/*`, сделать визуальный таймлайн прогресса по темам.

## Решения (зафиксировано)

| Тема | Решение |
|------|---------|
| «Мой профиль» | Текущий кабинет `/app` (статистика, продолжить, на проверке, чат) |
| «Программы» | Отдельный экран со списком программ |
| Верхняя шапка | Убрана на `/app/*` |
| Лого / тема / выход | В левом сайдбаре (десктоп) + в экране профиля (мобилка) |
| Таймлайн | Тема = кружок (% уроков); справа название; уроки — список под темой |
| Цвета кружков | `<100%` — серый; `100%` — зелёный; заливка по % |
| Подход | Отдельный StudentShell для `/app/*` (admin/landing без изменений) |

## Навигация

### StudentShell (`/app/*`)

- `AppChrome` не рендерит `AppHeader` на путях `/app` и `/app/...`.
- Layout оборачивает `Outlet` в student chrome.

**Десктоп (`md+`):**
- Левая колонка ~240px: логотип, пункты «Программы» / «Мой профиль», внизу ThemeToggle + выход.
- Контент справа.

**Мобилка:**
- Нижний таббар: 2 кнопки — «Программы», «Мой профиль».
- Тема и выход — на экране профиля (не в таббаре).
- `padding-bottom` у контента, чтобы таббар не перекрывал.

**Активный пункт:**
- Профиль: `/app`, `/app/support` (и близкие).
- Программы: `/app/programs`, `/app/programs/$id`, уроки внутри программы.

## Экраны

### Мой профиль — `/app`

- Приветствие, статистика, «продолжить», «на проверке», превью чата.
- Список программ **убран** с этой страницы.
- На мобилке: блок с ThemeToggle + выход.

### Программы — `/app/programs`

- Список доступных программ (карточки с прогрессом).
- Клик → `/app/programs/$programId`.

### Программа — `/app/programs/$programId`

- Компактная сводка «N из M уроков» (опционально ProgressStat).
- Вертикальный **TopicTimeline**:
  - кружки соединены вертикальной линией;
  - заливка кружка = % завершённых уроков темы;
  - неполная тема — серый; 100% — зелёный;
  - справа — название темы;
  - под темой — список уроков (открыть / %).

### Урок / Support

- Без смены модели; живут внутри StudentShell.

## Структура файлов

```
features/student-shell/     # layout: sidebar + bottom nav
features/student-home/      # профиль/кабинет без списка программ
features/programs/          # список программ + страница программы
components/lms/             # TopicTimeline (кружки + линия)
routes/app.tsx              # ZeroProvider + StudentShell
routes/app/programs/index   # список программ
```

Admin (`/admin`) и лендинг (`/`) не меняют chrome.

## Вне скоупа

- Новый экран «настройки профиля» (имя/email).
- Изменение доменной модели прогресса / Zero schema.
- Редизайн админки или лендинга.
