- Практика в уроках больше не встроенные TipTap-вопросы: активность «Практика» теперь ссылается на группу тестов (`testGroupId`, `questionCount`, `passPercent`), ответы ученика проверяются через систему попыток (`test_attempt`)
- Новый раздел админки «Тесты» (`/admin/tests`): список групп тестов, создание/редактирование группы, публикация
- Страница группы: список вопросов с типом ответа и статистикой ответов (верно/неверно/на проверке), добавление теста
- Редактор теста: TipTap-редактор текста вопроса (на основе TheoryEditor), выбор типа ответа, редактор вариантов, эталонный ответ (через answer-widgets), авто/ручная проверка
- Ссылка «Тесты» в меню админки
- Настройка практики в редакторе активности: выбор/создание группы тестов, количество задач в попытке, проходной балл
- Удалён устаревший TipTap-редактор вопросов практики (`PracticeEditor`, `PracticeRenderer`, узлы вопросов, sanitize/extract-хелперы) — не используется, весь функционал перенесён на группы тестов
- Демо-сид (`admin-seed`) теперь создаёт для каждого урока отдельную группу тестов с вопросами вместо TipTap-документа с вопросами
- Обновлён e2e-сценарий критичных путей: практика проверяется через создание группы тестов и прохождение попытки вместо встроенных вопросов
